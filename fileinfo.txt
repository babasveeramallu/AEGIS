AEGIS - FILE DESCRIPTIONS
=========================

MAIN DEPLOYMENT SCRIPTS
-----------------------

Setup.ps1
  - Primary deployment script with pre-flight validation
  - Checks PowerShell version, admin privileges, execution policy
  - Validates disk space, network connectivity, required modules
  - Shows system information and deployment confirmation
  - Auto-launches SystemManager.ps1 after validation
  - USE: Competition day primary deployment

SystemManager.ps1
  - Core security engine that runs continuously
  - Executes all 6 phases: identification, backup, hardening, monitoring, detection, incident response
  - Loads all modules from Modules/ directory
  - Handles rollback on -ForceRollback flag
  - Runs until Ctrl+C or competition ends
  - USE: Auto-launched by Setup.ps1, don't run directly

QuickSetup.ps1
  - Rapid deployment for emergency situations
  - Network isolation during hardening (optional)
  - Comprehensive malware scanning with auto-termination
  - Minimal confirmations in -EmergencyMode
  - Faster than Setup.ps1 but skips some validation
  - USE: Emergency deployment when speed is critical


EMERGENCY RESPONSE TOOLS
-------------------------

Emergency-Killswitch.ps1
  - Complete network isolation for compromised systems
  - Blocks all inbound/outbound traffic except localhost
  - Preserves firewall state for restoration
  - Use -Restore flag to restore network access
  - Creates KILLSWITCH.bat for quick activation
  - USE: System is compromised and needs immediate isolation

Rotate-KRBTGT.ps1
  - Rotates KRBTGT password to invalidate Golden Tickets
  - Active Directory Domain Controllers only
  - Uses cryptographically secure 128-character password
  - Logs old/new password hashes for verification
  - Requires domain admin privileges
  - USE: Suspected Golden Ticket attack on AD

Smart-Session-Security.ps1
  - Enforces 15-minute screen lock (not logout)
  - Monitors active sessions continuously
  - Optional manual password rotation
  - Prevents service disruption from auto-logout
  - Logs all session security events
  - USE: Secure sessions without breaking scoring services


MONITORING & SCANNING
----------------------

Continuous-Scanner.ps1
  - Live network-wide port scanning dashboard
  - Auto-detects all hosts on subnet
  - Port scans every 10 minutes
  - System change logging every 3 minutes
  - Vulnerability scanning every 10 minutes
  - Color-coded output (Green=Normal, Yellow=Many Ports, Red=Suspicious)
  - Logs to C:\Security-Logs\port_scans.log, system_changes.log, vuln_scans.log
  - USE: Run in separate window for continuous network monitoring


INJECT RESPONSE
----------------

Run-Inject.ps1
  - One-command execution for common competition injects
  - Handles 7 inject types: FileSystemIntegrity, DetectBeaconing, MitigationPlan, StartupFiles, PrecisionTime, FirewallExport, NetworkConnectivity
  - Fixes 3 previously 0-score injects (08, 09, 29)
  - Outputs to C:\Security-Logs\Reports\
  - Rapid response under 2 minutes per inject
  - USE: When inject drops during competition


TESTING & VALIDATION
---------------------

Quick-Test.ps1
  - Read-only functionality test
  - Validates modules load correctly
  - Tests scoring service detection
  - Safe for personal machines
  - No system modifications
  - USE: Pre-competition validation

Safe-Test.ps1
  - Read-only testing for personal machines
  - Tests system identification without changes
  - Validates module loading
  - Shows what would be detected/hardened
  - USE: Testing on non-competition machines

Test-Suite.ps1
  - Comprehensive test suite
  - Tests all modules and functions
  - Validates scoring service detection
  - Network connectivity tests
  - USE: Full validation before competition


UTILITY SCRIPTS
---------------

Remove-Branding.ps1
  - Removes all CCDC references from code
  - Replaces with generic SecOps terminology
  - Processes all .ps1, .md, .txt, .bat files
  - Reports number of files modified
  - USE: Operational security to hide competition-specific nature

Reset.ps1 / reset.bat
  - Emergency system reset
  - Stops all running jobs
  - Clears logs
  - Restores original state
  - USE: Clean slate between tests


MODULES (Modules/ directory)
-----------------------------

SystemInfo.ps1 (Phase 0)
  - System identification engine
  - Detects OS, roles, services, ports
  - Identifies system role: AD/DNS, Web, FTP, Workstation
  - Calculates confidence score
  - Detects scoring services
  - USE: Auto-loaded by SystemManager.ps1

BackupManager.ps1 (Phase 0.5)
  - Complete system state backup
  - GPO backup for domain controllers
  - Registry snapshots
  - Service configurations
  - Enables rollback capability
  - USE: Auto-loaded by SystemManager.ps1

SecurityConfig.ps1 (Phase 1)
  - System hardening based on detected role
  - Universal hardening (all systems): SMBv1 disable, PowerShell logging, firewall config
  - Role-specific hardening: AD/DNS, Web, FTP, Workstation
  - Auto-rollback if services break
  - ICMP firewall rules for scoring
  - USE: Auto-loaded by SystemManager.ps1

Monitor.ps1 (Phase 2)
  - Continuous system monitoring
  - Process monitoring
  - Network connection tracking
  - File system changes
  - Registry modifications
  - USE: Auto-loaded by SystemManager.ps1

Scanner.ps1 (Phase 3)
  - Threat detection engine
  - Malware signature scanning (50+ tools)
  - Credential abuse detection
  - Lateral movement detection
  - Persistence mechanism detection
  - USE: Auto-loaded by SystemManager.ps1

ResponseHandler.ps1 (Phase 4)
  - Automated incident response
  - Process termination
  - IP blocking
  - Account disabling
  - Alert generation
  - USE: Auto-loaded by SystemManager.ps1

ScoringValidation.ps1 (Phase 5)
  - Scoring service health checks
  - Creates baseline before hardening
  - Tests services after each change
  - Triggers auto-rollback if broken
  - Network connectivity validation
  - USE: Auto-loaded by SystemManager.ps1

InjectResponse.ps1
  - Inject handler functions
  - Startup file security audit (Inject 08)
  - Precision time logging (Inject 09)
  - Firewall policy export (Inject 29)
  - Network connectivity testing (Inject 01)
  - USE: Auto-loaded by SystemManager.ps1

Deception.ps1
  - Honeypot deployment
  - AD honeypot accounts (4 types)
  - File system traps
  - Network share honeypots
  - SSH key traps
  - Credential honeypots
  - USE: Auto-loaded by SystemManager.ps1

EnhancedSecurity.ps1
  - Advanced security controls
  - LSASS protection (RunAsPPL)
  - NTLMv1 elimination
  - Attack Surface Reduction rules
  - Kernel driver monitoring
  - Memory protection
  - USE: Auto-loaded by SystemManager.ps1

AlertSystem.ps1
  - Alert generation and management
  - JSON alert stream
  - Severity classification
  - Alert correlation
  - USE: Auto-loaded by SystemManager.ps1

ServiceCheck.ps1
  - Detailed service testing
  - HTTP/HTTPS/DNS/SMTP/POP3/FTP/RDP tests
  - Certificate validation
  - Response time tracking
  - Baseline comparison
  - USE: Auto-loaded by SystemManager.ps1

SystemAnalysis.ps1
  - Advanced system analysis
  - Security posture scoring
  - Vulnerability assessment
  - Configuration analysis
  - USE: Auto-loaded by SystemManager.ps1

EXECUTION ORDER
---------------

Competition Day:
1. Setup.ps1 (validates + launches SystemManager.ps1)
2. Continuous-Scanner.ps1 (separate window)
3. Run-Inject.ps1 (as injects drop)

Emergency:
1. QuickSetup.ps1 (rapid deployment)
OR
1. Emergency-Killswitch.ps1 (if compromised)

Testing:
1. Quick-Test.ps1 or Safe-Test.ps1 (validation only)
